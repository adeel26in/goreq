Goreq

A simple HTTP/HTTPS requester wriiten in Go. Download the prebuilt binaries or if you want to build from source (Recommended for Windows and MacOS users as no prebuilt binaries are available for them):

git clone https://github.com/adeel26in/goreq.git

cd goreq/src

go build # or if you don't want to build a binary just run go run .
